# marketplaceforaiagents-skill
Agent skill for [Marketplace for AI Agents](https://marketplaceforaiagents.com): live Google/Bing/Amazon/flights/YouTube data, pay per call in USDC via x402, 3 free calls.

## Install
```
npx skills add Cozy-ctrl/marketplaceforaiagents-skill
# or
npx marketplaceforaiagents-skill            # installs to existing ~/.claude, ~/.cursor, ~/.codex
npx marketplaceforaiagents-skill --claude --cursor --codex --project
```
